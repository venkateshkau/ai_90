# ai-90

## Goal
This is my first LLM call to Agent harness project. 90 days of learning. 

## Levels
| Level | Focus | Days | Dates | What you'll have at the end |
|---|---|---|---|---|
| L1 | Python + LLM API foundations | 1–13 | 08 Oct – 20 Oct | A tested CLI chatbot on GitHub; you know tokens, cost and streaming |
| L2 | Prompting & structured output | 14–27 | 21 Oct – 03 Nov | A versioned prompt library, typed extraction, a spec-summariser CLI |
| L3 | Tool calling & agents | 28–41 | 04 Nov – 17 Nov | A research agent with tools, guards, tracing and human approval |
| L4 | Embeddings & RAG | 42–55 | 18 Nov – 01 Dec | RAG over your own notes with citations, measured with recall@k |
| L5 | Evals & TDD for LLM apps | 56–69 | 02 Dec – 15 Dec | A golden-set eval suite running in CI, plus the CCA-F prep |
| L6 | MCP, harness & spec-driven | 70–83 | 16 Dec – 29 Dec | An MCP server, an AGENTS.md + EARS spec, and a harness write-up |
| L7 | Capstone & recap | 84–90 | 30 Dec – 05 Jan | A capstone repo, a demo video, your retro and the next 90 day plan |

## Project layout
- src/ai_90 — package code
- tests — pytest tests
- notes — daily logs
- posts — LinkedIn drafts
- specs — Will have specs written to drive AI for development
